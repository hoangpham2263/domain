Cài trên hosting (cPanel)
  1. Lấy IP hosting: cột phải của cPanel (Shared IP Address) hoặc email bàn giao.
  2. Điền tên + IP ở trên → "Tạo file trên GitHub" → Commit → Create pull request. Chờ duyệt.
  3. cPanel → Domains → Create A New Domain: nhập tên miền đầy đủ, chọn thư mục web.
  4. WordPress: Cài đặt → Tổng quan, đổi 2 địa chỉ thành https://tên-miền.
  5. Khi "Kiểm tra DNS" báo đúng IP: cPanel → SSL/TLS Status → Run AutoSSL để có HTTPS.
